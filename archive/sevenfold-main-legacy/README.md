# 七曜牌局 · SEVENFOLD

七子连珠 + 卡牌术式的像素风网页策略 Demo。你执「星火」先手，与弈者「墨鸦」在星盘上争夺七曜之位。即时术式在落子前改写棋局，延时秘式在暗处等待翻盘。

![七曜牌局标题画面](assets/preview-title.png)

## 运行

无需构建、无需服务器：

1. 直接双击 `index.html`，用 Chrome / Edge / Firefox 打开。
2. 如果浏览器对本地文件限制较多，也可以在目录中运行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

全部字体、图标和脚本都在本地，不依赖网络。

## 操作

| 操作 | 说明 |
| --- | --- |
| 点击手牌 | 查看效果并选取；即时牌在落子前，秘式在落子后 |
| 点击星盘 | 直接落子；选择目标牌后则选择目标 |
| 点击“发动术式” | 发动无需目标的即时牌 |
| 位移牌 | 先点星子，再点相邻的箭头格 |
| `1`–`7` | 快速选取对应位置的手牌 |
| `E` | 结束回合 |
| `Esc` | 取消选择 / 关闭弹窗 |
| 右上角“玩法 / 图鉴” | 查看完整规则与 13 张卡牌 |

## 规则

### 胜负

- 率先在横、竖、斜任意方向完成 **7 枚同色星子连珠**即获胜。
- 布下【六合改命】后，该方的胜利条件永久变为 **6 子连珠**。
- 【双生星】落下的星子计为 **2 枚**，可以更快凑成连珠。
- 星盘下满仍未分胜负则平局。

### 一回合

1. **抽牌**：回合开始自动抽 1 张，手牌上限 7。
2. **即时术式（可选）**：落子前可以发动 1 张即时牌。
3. **落子（必需）**：在星盘落下一枚星子；位移术式会代替落子。
4. **延时秘式（可选）**：落子后可以布下 1 张秘式。
5. 结束回合。

> 每回合最多只打出一张牌。你可以选择“即时牌 + 落子”，或“落子 + 秘式”，不能两者都出。

### 关卡与墨鸦的权能

标题画面的<b>棋力</b>和<b>关卡</b>是两件事：棋力决定墨鸦算得多深，关卡决定它额外拥有哪些权能。

| 关卡 | 墨鸦的权能 |
| --- | --- |
| **基础关** | 换营 + 双术 |
| **无技能关** | 无（原始规则） |

**【换营】** 你第 2、4、6… 次连成五子（横竖斜，双生按 2 枚算）时，双方星子归属对调——你刚连成的星路直接变成墨鸦的兵。**若墨鸦当时已经占优，换营不发动。** 只换棋盘上的星子：双生、金身跟着子走；手牌、暗牌、六合改命的胜利条件、封禁格与术式归属都不动。交换后如果墨鸦因此凑成七子，当场判胜。

**【双术】** 偶数回合（第 2、4、6… 回合）墨鸦可以发一张即时术式，落子后再布一张延时秘式。奇数回合仍然只有 1 张，玩家永远只有 1 张。

界面上，墨鸦面板会显示当前权能和你的五连续计（"再来一次就交换"），规则弹窗里有同一套说明。

### 明与暗

- **即时术式**：双方可见，立即产生影响。
- **延时秘式**：盖放后对方只能看到“暗牌”，直到触发、失效或对局结束才揭晓。
- 棋盘上的封禁格、定身格、已触发效果是公开信息。
- 【金身】能免疫敌方推动、爆裂与换影；己方布下的爆裂仍会摧毁自己的星子。

## 13 张卡牌

### 即时术式

| 卡牌 | 效果 |
| --- | --- |
| 四方封 · 铁壁 | 下一子落定后，封锁其上下左右四格 1 回合 |
| 斜四封 · 断翼 | 下一子落定后，封锁其四个斜角 1 回合 |
| 拓界 · 星图外环 | 星盘向四周扩展一圈（最大 19×19） |
| 双生星 · 重影 | 下一子计为 2 枚，参与所有连线 |
| 崩星 · 寂灭 | 下一子落下后爆裂，摧毁自身与周围八格全部星子 |
| 逐客令 · 斥候 | 推动一枚敌子一格；使用后不能落子，金身免疫 |
| 挪星步 · 换位 | 移动一枚己子一格；使用后不能落子 |
| 定身咒 · 钉星 | 指定空格，对方下回合必须落在该处 |

### 延时秘式

| 卡牌 | 效果 |
| --- | --- |
| 金身 · 不灭 | 指定己子 3 轮内免疫敌方术式 |
| 换影 · 镜界 | 以刚落的己子为锚，对方下回合落子后交换两子位置 |
| 六合改命 · 短歌 | 己方胜利条件永久改为 6 子连珠 |
| 噤声 · 封喉 | 对方下回合使用的第一张牌失效 |
| 策反 · 星蚀 | 3×3 策反区，对方下回合落入其中的星子转为你方 |

## 人机「墨鸦」

- 使用与玩家完全相同的棋盘、手牌和卡牌规则。
- 落子前做一次 **1 步回手的浅层 αβ 搜索**（迭代加深 + 地平线必挡延伸），能看穿「我造双杀」「对方下回合造双杀」。
- 威胁判断按双方**真实胜利条件**算（六合改命后是 6 子），并且把对方**明牌的 pending 即时术式**算进去（双生星 = 下一子计 2 枚）。
- 位移类卡牌有一道门禁：对方下一手就能赢时，不打出跳过落子的【挪星步】/【逐客令】；【逐客令】推子前会先试推，不会把敌子推进连珠。
- 只读取棋盘公开信息与自己的暗牌，**不会偷看玩家的延时秘式**。
- 三档棋力：见习（不搜索、留破绽）/ 棋师（搜索 2 层）/ 大棋士（搜索 4 层，600 ms 兜底），可在标题画面切换。
- BOSS 权能由关卡决定，与棋力正交；AI 会主动用满「双术」的多余牌位，也会在换营后立刻按新局面重新评估。

### 强度边界（实测，用 `tools/arena.js`）

| 实验 | 结果 |
| --- | --- |
| 大棋士 vs 改动前 | **60% / 62% / 74%**（三个种子各 100 局，先后手配对）→ 合计 **65%** |
| 其中起决定作用的一步 | 【双生星】从「只用来一步杀」改成「用来造双杀」：同批种子 46% → 60% |
| 搜索 2 / 4 / 6 层 | 55% / 54% / 52%（**卡牌改进之前**测的）——加深几乎无收益 |
| 完全不用卡牌重跑 100 局 | **100% 和棋**，169 格填满 |
| 大棋士 vs 见习 | 90% / 8% |

结论：13×13、7 子连珠下**纯落子本身接近和棋**，胜负主要由卡牌决定——所以这轮的提强几乎全部来自卡牌层的修正（双生星造双杀），而不是更深的搜索。想再上一个台阶，方向仍然是卡牌决策（崩星/策反/换影的主动用法），不是加深搜索。

> 本文档里的数字都可以复现：`node tools/arena.js --a new:hard:4 --b old:hard --games 100 --seed 2024`

## 技术

- 原生 HTML / CSS / JavaScript，无运行时依赖。
- 纯 DOM + CSS 像素美术；13 张卡牌图标与棋子均为内联 SVG 像素绘制。
- WebAudio 合成音效；`localStorage` 保存难度、音效开关与胜负战绩。
- 规则引擎与 AI 可在 Node 中独立运行。
- 响应式布局：桌面三栏、平板双栏、手机单栏 + 横向手牌。

## 测试

```bash
node tests/engine.test.js   # 23 项规则（含换营 / 双术）
node tests/ai.test.js       # 8 项人机行为
```

规则测试覆盖：七子胜利、双生计数、六合改命、两种封锁、拓界坐标平移、崩星与金身、位移、定身、换影、噤声、策反、抽牌洗牌、手牌上限、定身失效，以及**换营**（第偶数次五连续发、墨鸦占优时不发动、无权能的关卡不计数）与**双术**（偶数回合两张、奇数回合与玩家仍一张）等 23 项。

人机测试盯的是会直接送棋的错误：有杀要杀、有杀必挡、对方双生星待发时把 2 枚算进威胁、对方有杀时不打跳过落子的位移牌、不落被封禁格、整回合不崩、偶数回合把「双术」的两张牌都用满。这几条里有两项在改动前的版本上会失败。
