# 七曜牌局 · 音效清单（马里奥 · FC 正统音色）

- 音源定义：`js/sound.js` 末尾的 `CUES`
- 音色包：`nes`（红白机 2A03 脉冲波，毫秒级衰减、明亮干脆）
- 格式：44.1kHz / 立体声 MP3 @ 192kbps（有损）
- 重新导出：`node tools/render-sfx.js nes sfx && node tools/wav2mp3.js`
- 试听确认：`sfx-audition.html`

共 31 条，按 5 组分目录。


> MP3 编码器自带约 13ms 前导静音（LAME 固有延迟）。人耳基本无感，
> 但如果要在引擎里做采样级对齐，请改用 wav 版。

## 01-界面（5 条）· 按钮、悬停、无效、弹窗、开场

- `01-select.mp3` — 按钮 · 选牌（点任意按钮、键盘 1-9 选牌）
- `02-hover.mp3` — 悬停手牌（鼠标划过一张牌）
- `03-deny.mp3` — 无效操作（点到封禁格 / 非法目标）
- `04-modal.mp3` — 弹窗开合（图鉴、补给、弃牌、结算面板）
- `05-start.mp3` — 游戏开场（标题页点「开始对局」）
